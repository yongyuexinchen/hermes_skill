# 宏观05：地产投资分析

## 分析框架

房地产 = **宏观内核 + 市场化外壳**（内核原动力来自政策，外壳市场化运转）

左右分视角：
- **左侧（宏观）**：GDP影响 / 融资杠杆敞口 / 财政收支 / 居民财富与就业
- **右侧（行业）**：用销售/库存/开发指标审视行业节奏

## 房地产开发投资完成额

### 两大口径：
| 分类方式 | 主要组成 | 要点 |
|----------|----------|------|
| 按工程用途 | 住宅75%+办公楼+商业 | 住宅绝对主力 |
| **按构成** | **建安工程~63% + 土地购置费~25%** + 设备~2% | 分析主力口径 |

- **土地购置费不计入GDP**（从固定资本形成总额中扣除）
- 建安工程 = 建筑工程 + 安装工程
  - 施工面积 ≈ 建筑工程（平滑线）
  - 竣工面积 ≈ 安装工程

## 销售→库存→开发 联动

### 核心先行指标链条：
**PSL（棚改货币化）→ 销售↑ → 库存↓ → 土地供给↑→土地购置费↑ → 新开工↑ → 施工滞后**

### 2015-2018年复盘：
1. **2015年6月**：棚改货币化启动，PSL上升
2. **销售上升**→去库存（销售>施工速度）
3. **库存下降后**→政府增加土地供给
4. **土地购置费暴增**（地王频出）→抵消防地产开发投资的波动
5. **新开工上升但建安下降**之谜：地产商加速周转拿预售证→预售回款再拿地→施工后置
6. **期房销售占87%**是理解此行为的关键

## 资金来源

| 来源 | 占比(~21年) | 趋势 |
|------|-------------|------|
| 销售回款（定金+按揭） | >50% | 上升 |
| 自筹资金 | ~30% | 含明股实债/非标 |
| 国内贷款 | ~12% | 持续下降 |

- 个人按揭利率与房贷需求呈明显反向关系

## 房地产的宏观影响

### 直接+间接占GDP约20%：
- **直接投资**：占固定资本形成总额约23%（扣除土地购置费后约7-8%）
- **间接消费**：居住类消费 + 地产后周期消费（家电/家具/家政等）
- **间接投资**：土地出让金→居民部门→消费转化+资本形成

### 对就业的影响：
- 房地产业就业：1440万人（2.7%）
- **建筑业就业**：6000万+（12.7%）— 就业多但GDP占比仅7.2%
- → 建筑业是重要就业"蓄水池"

### 房地产敞口（2021Q3，合计约58万亿）：
- 个人按揭 63%
- 房企贷款 24%
- 非标 6%
- 另有对居民保交房敞口8.7万亿 + 各项应付款4.8万亿

## 土地财政与专项债风险

- 土地出让金净收入（仅20%可灵活支配）÷ 各省专项债利息 = 利息保障倍数
- 全国平均3.9倍；云南/天津 < 1倍
- GDP高度依赖土地出让金的六省需重点关注
