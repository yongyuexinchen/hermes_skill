# 宏观02：超储率 + 央行货币政策工具

## 超储率（超额存款准备金率）

超储率 = 超额存款准备金 / 存款总额，是衡量**银行间狭义流动性**的核心指标（每季度公布一次）。

### 五因子公式（Δ超额准备金）：

```
Δ超额准备金 = Δ外汇占款 + Δ对其他存款性公司债权 
              - Δ货币发行 - Δ法定存款准备金 - Δ政府存款
```

### 五因子分析：

| 因子 | 重要性 | 特征 |
|------|--------|------|
| **对其他存款性公司债权** | ⭐⭐⭐⭐⭐ 最重要 | 央行公开/非公开投放，对应麻辣粉酸辣粉等工具 |
| **政府存款** | ⭐⭐⭐⭐ 很重要 | 财政收税+发债 → 政府存款↑ → 超储↓；财政支出 → 反向 |
| 外汇占款 | ⭐⭐ | 占比大但波动不大 |
| 货币发行 | ⭐ | 稳定，仅春节有现金需求波动 |
| 法定准备金 | ⭐ | 难预测，央行在淡化使用 |

## 央行货币政策工具全景

### 核心工具：

| 工具 | 类型 | 期限 | 要点 |
|------|------|------|------|
| **逆回购（OMO）** | 短期利率引导 | 7天为主 | 利率走廊下限；使用最频繁；一级交易商参与 |
| **MLF（中期借贷便利/麻辣粉）** | 中期利率引导 | 3月-1年 | 降准替代品；可多次展期；LPR=MLF+90BP |
| **SLF（常备借贷便利/酸辣粉）** | 短期利率上限 | 隔夜-3月 | 利率走廊上限；银行主动发起→污名效应 |
| **PSL（抵押补充贷款）** | 结构性工具 | 3-5年 | 对象:政策性银行；用途:三农/小微/棚改 |
| **SLO（短期流动性调节）** | 辅助 | ≤7天 | 2016年后基本停用 |

### 利率走廊：
- **上限**：SLF利率（银行不愿主动借→明显高于市场利率）
- **下限**：逆回购利率（一级交易商最低融资成本）
- **基准利率**：DR007在走廊内波动

### 辅助工具：
- **TLF（临时流动性便利）** + **CRA（临时准备金动用安排）**：保障春节现金需求
- **CBS（央行票据互换）**：提升银行永续债流动性
- **国库现金定存**：随行就市，不反映政策意图，反映银行对存款需求强弱

## 政府存款详解

- 公式近似：政府存款 ≈ 一般公共预算收入 + 政府债券净融资 - 一般公共预算支出
- 税收占一般公共预算收入约85%
- **地方债**：包含一般债（用一般公共预算偿还）和专项债（有收益项目偿还）
- 缴税高峰→银行体系流动性减少→央行平滑

## PSL与棚改货币化

- PSL在2016年峰值约3.6万亿→用于棚户区改造货币化安置
- 2021年后PSL只降不增，央行在回收过程中可进行结构性调整
- 棚改货币化不会再现：饮鸩止渴、只是递延问题
