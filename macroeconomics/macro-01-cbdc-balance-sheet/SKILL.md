# 宏观01：总述 + 央行资产负债表

## 核心分析框架：三角铁体系

宏观经济可拆解为四大模块（形如三角铁）：

```
         央行（拎绳子的手）
          |
       银行体系（管道）
        /        \
   资本市场      实体经济
  （资产市场）   （GDP核算体系）
```

- **央行**：货币源头，通过管道连通银行体系
- **银行体系**：央行调控的传导中介，对应狭义流动性
- **资本市场/资产市场**：包括股市、大宗商品、地产市场（均有蓄水池属性）
- **实体经济**：GDP核算体系（支出法三驾马车 + 生产法三大产业）
- **财政**贯穿所有模块，可向各方向延伸

## 央行资产负债表

### 资产端（去向）：
| 科目 | 占比 | 说明 |
|------|------|------|
| 国外资产（外汇） | ~56% | 最大项，外汇占款是货币投放主渠道 |
| 对其他存款性公司债权 | ~30% | 央行对商业银行/政策银行的债权 |
| 对政府债权 | 很小 | 仅对中央政府 |

### 负债端（来源）：
| 科目 | 占比 | 说明 |
|------|------|------|
| 储备货币 | ~81% | 货币发行23% + 金融性公司存款52%（准备金） |
| 政府存款 | ~13.5% | 中央国库+地方国库 |
| 非金融机构存款 | ~5% | 第三方支付平台存款 |

### 三大来源对应三大职能：
- **发行的银行**：货币发行（自己印的钱）
- **银行的银行**：商业银行准备金存款
- **国家的银行**：政府存款

## 关键概念

1. **被动扩表 vs 主动扩表**：
   - 被动：外汇流入→被迫投放人民币（外汇占款为主阶段）
   - 主动：央行通过货币政策工具主动投放（2014年后）
   - 人民币从主权货币→具有外储货币属性（温铁军观点）

2. **中国无法QE的原因**：国债现券交易是QE前提，我国国债作为抵押品而非现金交易

3. **M0计算**：货币发行 - 库存现金 = 流通中货币

4. **基础货币（高能货币）**：主要由外汇流入和央行主动投放两部分构成

## 分析要点

- 央行报表的核心是会计主体与相关各方的关系
- 资产负债表左侧=去向（资产）、右侧=来源（负债）
- 人民币同时具有货币属性和债券属性，分析时需区分
- 政府存款的变化可反映财政资金拨付进度（如专项债到位但未开工→政府存款增加）
