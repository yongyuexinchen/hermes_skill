# 宏观10：利率框架

## 基准利率：DR007

### 为什么是DR007？
| 选择 | 排除原因 |
|------|----------|
| 一年期定存利率 | 2015年后不再波动，行政化而非市场化 |
| 央票利率 | 已退出历史舞台 |
| Shibor隔夜 | DR001波动太大 |
| R007 | 含非银机构信用利差，不够纯粹 |
| 买断式回购 | 成交额极小（可忽略） |

**DR007**：存款类机构、7天质押式回购利率
- 质押式回购中1天占80%+7天占10%=90%
- DR007更稳定、更纯粹反映银行间短期资金成本

### 利率走廊：
- **上限**：SLF利率（污名效应→明显高于市场利率）
- **下限**：7天逆回购利率（一级交易商最低成本）
- **基准**：DR007在走廊内波动

## 短期利率 vs 中长期利率的本质区别

| 维度 | DR007（7天） | Shibor 3个月 |
|------|-------------|-------------|
| 反映对象 | **金融机构交易成本** | **实体融资需求** |
| 期限 | 7天内（90%成交） | 3个月（最活跃期限） |
| 用途 | 借短买长（赚息差） | 银行放贷的资金成本 |
| 实体需求相关性 | 弱 | 强 |

- 区别在于**期限**，而非拆借vs回购

## 无风险利率（Rf）

- **中国Rf = 国开债**（利息不免税，类比美国国债）
- **中国国债 = 利息免税**（类比美国市政债）
- 选国开债原因：成交额是国债的2-2.5倍（更活跃）+ 不免税（与分母端匹配）

### 银行买债vs放贷：
- 贷款收益 = 票面利率 - 税收 - 风险权重成本 - 不良率
- 剔除税收和资本占用后，贷款实际收益并不明显高于债券
- 但放贷带来存款派生和中间业务收入→银行仍倾向放贷

## 利率认知三层次（徐小庆框架）

### 层次1：通胀决定利率（2003-2012）
- 十年期国债与CPI高度一致
- 但猪肉是CPI最大波动项→利率≠猪肉决定（同源异象）
- 失效证据：08底利率见底但通胀到09年7月才见底（错6个月）

### 层次2：名义GDP增速（经济增长）决定利率
- 利率 ≈ 工业增加值（实际增速）+ PPI（价格）= 名义GDP增速
- 但2013-2014年名义GDP躺平而利率强势上行 → 需要更高维度解释

### 层次3：资金需求（经济模式）决定利率
- **不同增长模式对资金需求不同**：
  - 制造业驱动 → 低杠杆、低资金需求
  - 基建+地产驱动 → 高杠杆、高资金需求
- 2013年的利率上行 = 存量债务大量到期+借新还旧维持杠杆率
- 实体经济杠杆率同比增速滞后一年与十年期国债高度一致

## 货币供给的投放机制演变

### 2014年前：被动扩表（外汇流入为主）
- 外汇流入→被动投放人民币→流动性↑利率↓→同时人民币升值
- **新兴市场特征**：利率下降 + 汇率升值 同时发生
- 央行用央票回笼多余流动性

### 2014年后：主动扩表（央行工具为主）
- 外汇见顶下行→央行主动通过MLF等投放→对冲外汇流出
- 流动性先到大银行→再到中小银行（通过同业存单）
- **R007与DR007的差**由此产生（中小行发存单成本更高）
- 利率与汇率开始**同向变动**（代表央行独立性增强）

## 利率与汇率

- 美元指数反向描述全球经济（美元强=全球弱）
- 中债与美元指数逆序高度一致（20年级别）
- 中国增量占全球经济增量的权重越来越大

## 资金需求双层分析

### 实体层面：
- 核心看**房地产**（基建是对冲工具，制造业不依赖高杠杆）
- 社融至少20-22%流向房地产，贷款28%+流向房地产
- 商品房销售面积是利率的核心领先指标

### 金融层面（空转流动性）：
- 金融债务增速 = 银行资产增速 - 社融增速
- **空转流动性↑ → 实体资金需求相对↓ → 利率↓**
- 实体经济部门 vs 金融部门债权的相对增速，可以解释Shibor 3个月与DR007的分化

## 周期视角

- PMI与经济景气股指波动整体服从同一周期
- 股指更多反映制造业，利率反映所有实体的资金需求
- 在"高杠杆债务扩张"阶段（2009-2013），PMI与利率的关联被打破
