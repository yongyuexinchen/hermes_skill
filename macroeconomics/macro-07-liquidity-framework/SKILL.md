# 宏观07：流动性框架（三表联动）

## 核心逻辑

**资产负债表** 的天然结构：
- **资产 = 资金去向 = 资金需求**
- **负债 = 资金来源 = 资金供给**

三大核心报表：

| 报表 | 说明 |
|------|------|
| 货币当局资产负债表（央行） | 高能货币（基础货币）创造 |
| 其他存款性公司资产负债表（商业银行等） | 信用创造（信贷） |
| 存款类金融机构人民币信贷收支表 | 补充口径，含M0直接数据 |

## M2的结构与来源

### M0 = 货币发行（央行） - 库存现金（商行）
### M1 = M0 + 单位活期存款（非金融企业+机关团体）
### M2 = M1 + 准货币（单位定期+个人存款+其他存款）

M2资金来源拆解（四主体）：

| 主体 | 金额(~2022.1) | 对应科目 |
|------|---------------|----------|
| 实体部门活期（企业+机关团体） | ~50.8万亿 | 非金融机构及住户负债-活期 |
| 实体部门定期（主要是企业） | ~43.7万亿 | 非金融机构及住户负债-定期 |
| 居民部门（全部存款） | ~108.7万亿 | 住户存款 |
| 非银金融机构存放 | ~24.8万亿 | 对其他金融性公司负债 |

## 社融与M2的对应分析

### 按主体分析净供给/需求：

| 部门 | 资金供给 | 资金需求 | 净额 |
|------|----------|----------|------|
| **居民部门** | 108.7万亿 | 71.2万亿 | **净供给37.5万亿** |
| **实体部门** | 94.5万亿 | 136.9万亿 | **净需求42.4万亿** |
| 差额 | | | 4.9万亿（银行体系弥补） |

### 为什么M2 < 社融，且缺口不可靠？

- **M2 = 银行体系框架下的资金供给**（从出资方统计）
- **社融 = 全社会的资金需求**（从融资方统计，包含所有出资方）
- 非银行主体购买的政府债和企业债（~30万亿差额）不在M2统计范围内
- M2和社融各经历多次口径调整→缺口变动远大于经济规律本身

### 分析建议：
- **不要用总量缺口**，按主体拆开分析
- 用M2-M0-其他存款 与 社融人民币贷款对比
- 或直接用商业银行报表的"对非金融机构及居民部门债权"分析

## 关键对应关系

- 央行：基础货币创造（高能货币）
- 银行：信用创造（信贷派生）
- 银行对政府债权74%为存款性公司持有
- 地方政府存款主要在央行，仅有小部分在商业银行（财政性存款~6000亿差额）
- 央行的"其他负债"约38.7万亿≈商业银行二级资本债+所有者权益（扣除实收资本）
