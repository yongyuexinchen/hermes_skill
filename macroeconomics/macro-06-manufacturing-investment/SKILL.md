# 宏观06：制造业投资分析

## 四大投资分类（2021年占比）

| 类别 | 占比 | 特征 |
|------|------|------|
| **制造业投资** | ~33% | 民营为主，市场化 |
| 房地产投资 | ~23% | 宏观内核+市场外壳 |
| 基建投资 | ~25% | 逆周期工具 |
| 其他 | ~19% | |

## 趋势项：工业占GDP比重

- 制造业固投的**长期趋势由工业占GDP比重决定**
- 工业占比持续下降的原因：
  1. **外需下降**（出口占GDP比重在06年后见顶回落，贸易红利周期结束）
  2. **内需始终不足**（地产+基建拉动的消费远小于出口红利）
  3. 劳动力成本并非主因（制造业就业人数占比直到13年才下降）
  4. 全球全要素生产率近5年几乎停滞，技术溢出减少
- 2亿进城务工人员无城市户籍→边际消费倾向低于城镇→抑制内需

### 行业结构分化：
- 资产和营收增速双双落后：上游去产能领域 + 劳动密集型（外移）
- ICT/医药/专用设备表现靠前

## 波动项：传导链条

```
外需订单 → 原材料存货↑ → 产成品存货↑ → 生产↑(工业增加值) 
→ 产能利用率↑ → 利润↑ → 固定资产投资↑
```

### 五指标分析（用来替代生产指数）：
| 指标 | 效果 | 备注 |
|------|------|------|
| 工业增加值 | 一般 | 趋势项强，波动项弱（躺平） |
| 用电量 | 尚可 | 数据质量有待考量 |
| 工业企业利润 | 波动大 | 年频，解释力有限 |
| PPI | 参考 | 与利润同向 |
| 产能利用率 | 最直接 | 但仅17年起，太短 |

**结论：单一指标均有缺陷，需结合存货周期综合分析。**

## 库存周期（短周期）

- 四阶段划分：用产成品存货 + PPI
- **每次存货上行时，制造业固投表现更好**
- 原材料存货拐点领先产成品存货拐点

## 朱格拉周期在中国

- 过去20年**没有明显朱格拉周期**，三大趋势压制：
  1. 人口红利周期（15-64岁占比2010年见顶）
  2. 贸易红利周期（加入WTO→次贷危机后结束）
  3. 地产基建周期（次贷后成为稳增长抓手）

- 未来：总量朱格拉周期仍难出现，但**结构性朱格拉周期**可能出现（高技术/双碳/专精特新产业政策驱动）

## 上中下游划分

| 层级 | 代表行业 | 要点 |
|------|----------|------|
| 上游 | 采掘/采矿 | 供给侧改革后较独立 |
| 中游 | 化工/非金属/黑色/有色/设备 | 外需依赖20%+，占出口交货值60-70% |
| 下游 | 汽车/医药/食品/纺织 | 对接消费者，由内需驱动 |

- **中游>下游 → 外需>内需**（关键判断）
- PMI新出口订单是最领先的PMI分项指标

## 分析总结

1. **长期看产业政策**（30年双碳/高技术→超朱格拉周期的大趋势）
2. **中期看外需**（出口订单对制造业有决定性影响）
3. **短期看库存周期**（存货是最可靠的短期先行指标）
