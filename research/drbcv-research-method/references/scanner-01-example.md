## 使用的模式

- **relation_mode**: `name`（名称引用）
- 概念命名：中文全名 + 括号消歧，如 `"未定式（7种）"`、`"ε-N语言（伊普西隆-大恩语言）"`
- 关系引用通过 `concept[].name` 精确字符串匹配

## 验证过程

1. 初次写入后运行自定义验证脚本，发现 27 个关系引用不匹配
2. 根本原因：关系中的 `from`/`to` 使用了概念名的简写/别名，而非 `concept[].name` 的确切值
3. 修复方案：逐一比对关系引用与概念名，确保完全一致（含括号注解）
4. 二次验证通过：36 concepts, 38 relationships, all checks OK

## 对 Scanner 任务的启示

1. **3 篇中等文章 ≈ 35-40 概念** → 可作为单 Agent 扫描的规模基准
2. **名称引用模式需要严格的全局唯一命名** → 歧义短名（如「未定式」→「未定式（7种）」）必须在扫描时预先消歧
3. **关系验证不可跳过** → 即使直觉上认为引用正确，也需自动化验证捕捉字符串匹配错误
4. **LaTeX 片段验证** → 检查 `$...$` 配对数量是否为偶数，可捕捉截断/不完整公式
5. **概念类型应扩展** → DRBCV 原定 `discriminant/connection/mixed/procedure` 不覆盖定义类概念，实际扫描中需要 `definition/theorem/method/proof` 等类型
