# Sources 索引文件模式

## 结构

每个领域 vault 的 `Sources/` 目录下的 .md 文件作为该领域文章集的索引，使用 YAML frontmatter 的 `covers:` 字段列出该文章集中包含的所有概念（以 Obsidian `[[wikilink]]` 格式）。

## 示例

```yaml
---
title: "高等数学 - 导数与微分"
type: source
date: 2026-07-16
domain: calculus
covers:
  - "[[导数定义]]"
  - "[[基本求导公式]]"
  - "[[四则运算法则（求导）]]"
  - "[[链式法则（复合函数求导）]]"
  - "[[高阶导数]]"
  - "[[隐函数求导]]"
  - "[[参数方程求导]]"
  - "[[微分]]"
---

# 高等数学 - 导数与微分

> 原始文章：
> - `Articles/_导数定义_不会做题？..._原文.md`
> - `Articles/02.导数与微分第一节 导数概念_原文.md`
> - ...

内容包括：导数定义、基本公式、求导法则、高阶导数、隐函数、参数方程、微分。
```

## 使用规则

1. **`covers:` 是概念清单的权威来源** — 建卡前先读 Sources/ 索引文件，以 covers 列出的全部概念名为准，不遗漏、不超建
2. **`[[wikilink]]` 必须精确匹配** — 概念名必须与即将创建的 `Concepts/概念名.md` 文件名完全一致，否则 Obsidian 无法解析链接
3. **`Articles/` 引用** — body 区域用引用列表列出该来源对应的一篇或多篇原始文章文件名
4. **跨领域引用** — 当概念跨领域（如 \"极限\" 出现在多个领域 vault），用 `cross_ref` 在概念卡 frontmatter 标注，而非在 Sources 索引中处理
