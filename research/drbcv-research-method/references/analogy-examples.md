# 类比示例集（用户精选 + 本轮新增）

用户要求每张知识卡必须有「类比」栏。以下是经两轮大规模建卡验证的黄金示例，供建卡时参考风格。

## 用户原始示例（黄金标准）

### 定积分
> 定积分就是把不规则图形切成无数极薄的「薯片」，每片近似矩形，把所有薯片的面积加起来，切得越薄越精确。曲边梯形的面积 = 薯片堆的总面积。

### DHCP 攻击（最经典）
| 网络世界 | 浴场世界 |
|---------|---------|
| 客户端 | 你（光溜溜进去，啥也不知道） |
| DHCP Discover 广播 | 大喊一声："谁是搓澡师傅？！" |
| 合法 DHCP 服务器 | 真搓澡师傅（有工牌，但声音小/来得慢） |
| 流氓 DHCP 服务器 | 假搓澡师傅（嗓门大、跑得快、先到你面前） |
| Offer 报文 | "我是！跟我来！" |
| 假网关/DNS | "沐浴露"（其实是不可描述的热液体） |
| 发现真相 | 跑到前台："你们搓澡师傅用的啥？"→"我们没有搓澡师傅"→"我靠！" |

## 数据结构类（本轮 86 张卡产出）

### 栈 → 手枪弹夹
最后压入的子弹最先射出。拿中间那颗？先把上面全卸了。

### 单链表插入 → 食堂插队
先搭小红肩（接后链），再让小明搭你肩。顺序反了→整队人丢光。

### 队列 → 排队买奶茶
先来先喝。循环队列=环形跑道，跑到头绕回来。

### 时间复杂度 → 发传单
O(1)=喇叭广播，O(n)=一个个递，O(n²)=每人递一张还要签字确认。

### 折半查找 → 猜数字
1-100，每次猜中间，最多7次。"50?大了→25?小了→37..."

### 散列表 → 快递柜
手机号→柜子号。冲突=两人分到3号柜。拉链法=挂小箱子。开放定址=3满了去4→4满去5。

### 红黑树 → 黑社会堂口
新来的（红）要守五条规矩才能转正（黑），层级不能太悬殊。

### 快速排序 → 军训排队
选基准（pivot），比他矮站左边，比他高站右边，左右各自再排。

### BFS / DFS → 朋友圈找人 / 走迷宫
BFS=一层层扩散；DFS=一条路走到黑，死胡同就退。

### 最小生成树 → 铺光缆
N个城市之间铺光纤，覆盖所有城市且花费最少。

## 线性代数类（本轮 20 张卡产出）

### 行列式 → 方阵的面积/体积
2阶=平行四边形面积，3阶=平行六面体体积。两行相同=积木叠一起没体积→行列式=0。

### 秩 → 足球队真正能踢的人
大名单30人，场上只能上11个。冗余再多，秩不变。

### 线性相关 → 团队混子
可以被其他人顶替，删掉不影响战斗力。无关=每人不可替代，少一个降维。

### 通解 → 特解=找到门，齐次通解=在房间里随便走
通解 = 走到门口 + 在屋子里闲逛的自由度。

### 特征值与特征向量 → 变形记
矩阵A作用后只是把x拉长/缩短λ倍（方向不变）。像拉伸照片滤镜：某些方向只是放大。

### 对角化 → 换个角度看问题
找"天然坐标系"（特征向量基），矩阵变成最简单的对角形。

### 施密特正交化 → 把乱棍子掰成垂直脚手架
每次拿一根新的，减去在已搭好棍子上的投影，剩下的是垂直分量。

### 正定二次型 → 永远>0的碗
开口向上的抛物面，除原点外所有点都在碗上方。

## 风格要点
1. **越夸张越好记**：浴场、弹夹、黑社会堂口——场景越具体越有效
2. **必须配映射表**：概念世界 ↔ 现实世界，逐项对应
3. **一句话比喻是入口**：读者只记住一句话就够了
4. **抓住核心机制**：不是"栈像一摞盘子"就完了，要说"拿不到中间那个"
