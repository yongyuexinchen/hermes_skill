# Reality Client Config Reference

Quick reference for building VLESS+Reality client configs from 3X-UI panel values.

## What you need from 3X-UI panel

From the inbound → 编辑 → 安全 tab:

| Field | Panel Label | Example |
|-------|-------------|---------|
| Server IP | (from email) | `192.255.128.175` |
| Port | 端口 | `34356` |
| UUID | (auto-generated, check 协议 tab or inbound list) | `autogenerated` |
| Public Key | 安全 tab → second textbox | `0fbmDJwB4N7YHy_t_8uCLSLUjaQhIutUE5mwad42UR4` |
| Short ID | 安全 tab → dropdown value | `6ba85179` |
| Target SNI | 目标 field | `www.microsoft.com` |
| Spider X | 安全 tab → first textbox | `/wDaObIf48AjXFlk` |

## VLESS share link format

```
vless://<UUID>@<IP>:<PORT>?encryption=none&flow=xtls-rprx-vision&security=reality&sni=www.microsoft.com&fp=chrome&pbk=<PUBLIC_KEY>&sid=<SHORT_ID>&type=tcp&headerType=none#US-Reality
```

## Clash Verge manual proxy entry

In Clash Verge Rev → Profiles → manually add:

```yaml
proxies:
  - name: "US-Reality"
    type: vless
    server: <VPS_IP>
    port: <PORT>
    uuid: <UUID>
    network: tcp
    tls: true
    servername: www.microsoft.com
    flow: xtls-rprx-vision
    reality-opts:
      public-key: <PUBLIC_KEY>
      short-id: <SHORT_ID>
    client-fingerprint: chrome
```

## Test command

```bash
# After importing into Clash Verge, test through the mixed port
curl -x http://127.0.0.1:7897 -s -o /dev/null -w "%{http_code}" --max-time 10 https://www.google.com
# Expected: 200 or 302

# Also test Claude accessibility (the reason for US VPS)
curl -x http://127.0.0.1:7897 -s -o /dev/null -w "%{http_code}" --max-time 10 https://api.anthropic.com
# Expected: 404 or 401 (means IP is NOT blocked by Anthropic)
```
