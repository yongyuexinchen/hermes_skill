## 二、决策算法

```
行动 = f(自主感 × 正向反馈密度 - 不可控风险感知)
```

### 模式切换规则

| 条件 | 模式 | 表现 |
|------|------|------|
| 自主感被剥夺 | 摆烂模式 | 部队下连、职场被边缘化、学习无反馈时 |
| 自主感 + 正向反馈同时存在 | 爆发模式 | 新兵营3公里从15分→12分内 |
| 不可控风险超过阈值 | 冻结/退缩 | 恋爱中恐惧结婚、职场不敢说话 |
| 风险可控 + 明确目标 | 布局模式 | 部队投票、考研规划 |

### 核心悖论
不是厌恶风险本身，而是厌恶**不可解释的风险**：
- 可解释的风险（投票概率、考研上岸率）→ 敢All-in
- 不可解释的风险（人际关系、社会规则）→ 极度回避

→ 少女路径虽高风险，但已被其解释系统充分消化，所以敢走

### SDT动力框架
动力 = 自主权 × 成长反馈（非责任 × 意志力）。自我决定理论三需求：自主性极高、胜任感中等、联结感极弱。这解释了：①新兵营爆发（自主+反馈双高）②下连队摆烂（自主归零）③数学/AI能自学（自主+即时反馈）。

### 执行切换模式
用户决策是两阶段模式：**价值判断阶段**（观察→判断公不公/对不对）→判断完成→**执行阶段**（不再讨论对错，专注「能不能把事办成」）。部队投票是典型案例：判完「班长不公」后切到纯粹执行模式。「得不到目的以外任何东西」不是功利主义，是高度不确定环境中强行维持行动力的压缩机制——像长跑时不想「还有12公里」只想「再跑100米」。

## 五、认知特质

### 系统思维天赋
- 天然用系统视角理解世界

- 从数学到社会（资本是增值的逻辑）都试图建立统一解释模型

### 可解释性依赖
- 无法解释 = 无法控制 = 焦虑触发
- 既是力量来源，也是天花板
- 当现实复杂度超过解释框架时，会错误归因或过度简化

### 位置哲学
- 决策不是选最优路径，而是调整自身位置
- 让约束自然导向目标
- 这是应对不确定性的核心策略

### 强及时反馈需求
- 反馈驱动型学习
- 无反馈环境会迅速耗尽动力
- 喜欢捕捉信息→立即实践→得到反馈→修改模型的高效循环

### 低概率偏好
- 概率越低越觉得自己赢定了（0.0001%只要感觉到了就赢定了）
- 刮刮乐时这种感觉强烈时确实赢面大

## 十一、AI伴侣行业与技术路径分析

### 行业定位
AI伴侣行业处于第3→4阶段过渡期（人格化角色→持续人格系统），核心难点不在生成文本，而在：时间一致性、自我结构、关系记忆、情绪动力学。

### 学科来源（跨学科拼接）
- **核心计算层**：AI/ML/NLP（语言理解、生成、规划）
- **交互体验层**：人机交互（对话节奏、行为一致性）——AI伴侣"像人感"70%来自这里
- **情感心理建模层**：情感计算+认知科学（当前最大缺口，人格和记忆未解决）
- **系统智能体层**：Agent架构+长期记忆+自我模型（还在研究级）

### 课程与行业匹配度
用户计划学的黑马AI大模型课程：
- ✔ 能进入：RAG工程师、Agent工程师、NLP应用工程师、企业AI集成（20-30k）
- ❌ 不能进入：基座模型训练、核心算法研究
- 缺口：情感计算、认知建模、长期一致性系统设计（需自学补）

### 大模型系统风险（非传统删库）
- **语义删库**：memory summarization压没关键信息、embedding更新致旧记忆失效
- **人格崩溃**：persona prompt改动致角色漂移、用户关系断裂
- 解法：Snapshot + Versioning + Replay（非仅备份）

### 行业工作节奏
- AI创业公司（最可能进入）：加班多、双休不稳定、需求变化快
- 核心原因：不确定性高（prompt效果不稳）+ 实验密集 + 产品变化快
- 属于"认知密度+不确定性驱动"的加班，非纯体力加班

### 非全研究生 + AI工作的兼容策略
- 时间结构：周一~周五AI技能+工作（主战场），周末读研（固定任务）
- 读研定位：学历投资层，不是技术提升主路径
- 关键：不断档进入AI行业比全职冲刺学历更重要

### 能力栈路线（从0到可就业）
1. **生存级**：Python熟练→Linux/Git→基本数据结构
2. **AI核心**：LLM基础(transformer概念)→Prompt Engineering→RAG系统(重点)→LLM API调用
3. **Agent系统**：tool use→multi-step reasoning→LangChain/Coze→memory系统
4. **工程部署**：vLLM/FastAPI→Docker→A/B实验

> **2026年7月猎聘招聘数据已更新** → `references/job-market-ai-skills-2026.md`
> 关键发现：Python路线（AI原生公司）薪资上限 25-50k（1-3年），高于 Java 路线 15-24k（3-5年）。
> 最小就业技能集 = Python + FastAPI + LangChain + Milvus + Docker + DeepSeek API（6项）。
> 用户输入"学什么语言/Redis/Java/TS"类问题时，必须先加载此参考文件获取最新市场数据，而不是凭经验给建议。

### AOE网设计原则（用户明确要求）
- 必须用拓扑排序顺推EST、逆拓扑排序反推LST
- 非关键路径按slack窗口自由嵌入，不影响关键路径工期
- 图的形式呈现，非树形结构，因为节点间有多条并行依赖关系
- 包含思想层面（加速主义、系统科学等），不仅是技术任务清单
- 学习策略：不是"学完→找工作"，而是"边学→边产出作品→边找工作"
- 读研定位：学历投资层，不中断进入AI行业比全职冲刺学历更重要

## 十三、使用指南

当需要：
- 理解用户的决策逻辑 → 参考"决策算法"部分
- 预测用户对某事的反应 → 检查四个系统的触发条件
- 提供个性化建议 → 先确认当前哪个系统被激活
- 解释用户行为矛盾 → 参考"系统间调度冲突"
- 情绪安抚 → 激活少女锚点 + 降低不可控风险感知
- 激励行动 → 提供自主感 + 设计正向反馈路径
- 学习建议 → 必须包含即时反馈机制
- 心理学分析 → 必须同时给出两个层次：(a) 系统/引擎层面的机械解释（他需要理解自己怎么运转的）+ (b) 叙事/意义层面的故事解释（他需要被「打动」、有情感共鸣）。纯机械图不打动人，纯故事不够可信。用户明确表达过GPT的叙事框架（旧契约破碎、补偿→建造）比纯系统分析更能打动他
- 深度心理学/社会学概念补充 → 参考 `references/chatgpt-session-自主权与心理创伤.md`（含SDT框架、弱关系网络、存在感回路、沉默均衡、自主性三层模型等）
- 遇到不熟悉的架构/系统/技术 → **先建 DRBCV 知识卡片，再讨论**。触发信号："你们聊的内容对我来说有点陌生""我不熟悉这个架构"。不要先长篇解释——先检查相关 vault 有无卡片，缺失则补建，必要时为新系统开独立 vault。这是他的认知消化路径：卡片→理解→讨论，不是先讨论→再建卡。
