# 技术周期映射分析框架

## 概述

将当前技术浪潮映射到历史技术泡沫周期，验证「基础设施泡沫 → 破裂 → 廉价基础设施 → 应用爆发」假设。

## 经典技术周期对照表

| 技术浪潮 | 触发事件 | 泡沫期 | 泡沫破裂触发 | 破裂后遗产 | 应用爆发时间 |
|----------|---------|--------|------------|-----------|------------|
| **铁路** | 1840s 建设 | 1845-1847 | 过度建设 | 廉价铁路网 | 1850s-1860s |
| **电力** | 1882 爱迪生电站 | 1880s-1890s | 过度投资 | 廉价电力基础设施 | 1900s-1920s |
| **无线电** | 1920 KDKA | 1920s | 1929 大萧条 | 广播基础设施 | 1930s-1940s |
| **互联网** | 1995 Netscape IPO | 1995-2000 | 2000.3 纳斯达克见顶 | 廉价光纤宽带 | 2004-2012 |
| **AI** | 2022.11 ChatGPT | 2023-2026? | ? | 廉价 GPU 算力 | ? |

## 分析框架：6 个阶段模型

```
触发事件 → 早期炒作 → 投机泡沫 → 泡沫破裂 → 废墟重建 → 应用爆发
```

### 阶段判断指标

| 阶段 | 估值指标 | 投入指标 | 收入指标 | 舆论指标 |
|------|---------|---------|---------|---------|
| **早期炒作** | PE 正常偏高 | 资本开始流入 | 极少量收入 | 媒体开始报道 |
| **投机泡沫** | PE > 30, Shiller > 30 | 疯狂 CAPEX | 收入 < 投入 10% | "这次不一样" |
| **泡沫顶部** | Shiller > 40, 集中度极端 | 每日烧钱数十亿 | CEO 承认泡沫 | 央行密集警告 |
| **破裂初期** | 单日暴跌 > 15% | 项目冻结 | 收入证伪 | 恐慌蔓延 |
| **废墟重建** | 估值触底 | 人才/资产廉价 | 幸存者盈利 | 无人关注 |
| **应用爆发** | 估值合理 | 基础设施免费 | 利润爆发 | 不知不觉改变生活 |

## 数据采集清单

对目标技术浪潮，需收集以下维度的数据：

### 1. 估值数据
- [ ] 龙头公司市值及涨幅（如 Nvidia $1T→$5T）
- [ ] 板块集中度（如前5大公司占指数比例）
- [ ] Shiller CAPE / 远期 PE 与历史对比
- [ ] 单日最大跌幅事件

### 2. 投入数据
- [ ] 行业总资本支出（年度/预估）
- [ ] 龙头公司单季度/年度投入
- [ ] 债务融资比例（私募信贷 vs 股权）
- [ ] 数据中心/基础设施建设规模

### 3. 收入/盈利数据
- [ ] 龙头公司 AI 收入 vs 投入
- [ ] 行业 AI 项目盈利比例
- [ ] 预期盈利时间线
- [ ] 生产力影响实证研究（如 NBER 2026年2月报告）

### 4. 权威信号
- [ ] 央行/IMF 警告
- [ ] 内部人士（CEO）公开承认泡沫
- [ ] 知名投资者（Dalio、Dimon）表态
- [ ] 反方观点（Goldman Sachs、Morgan Stanley）

### 5. 历史对照数据（至少 2 个历史周期）
- [ ] 历史泡沫的涨幅/跌幅百分比
- [ ] 历史泡沫破裂后的幸存率
- [ ] 历史泡沫中幸存者后来成为巨头的案例
- [ ] 历史泡沫后基础设施廉价化的量化数据

## 应用领域分析模板

对每个预判的应用领域，分析 4 个维度：

```
领域名称：
├── 技术突破（已实现 vs 在研）
├── 当前实际进展（演示 vs 实际落地）
├── 瓶颈（技术、成本、时间、监管）
├── 泡沫后逻辑（廉价基础设施如何消除瓶颈）
└── 判断（0-5分 + 时间线估计）
```

## 关键引语（历史佐证）

> "Nothing important has ever been built without irrational exuberance."
> — Fred Wilson（VC，互联网泡沫中亏损 90% 净值）
> 
> 解释：互联网泡沫中铺设的过量光纤、训练的工程师、验证的商业模式，成为 Web 2.0 的基石。
> 类似地，AI 泡沫中过量采购的 GPU 和数据中心将在泡沫后成为廉价基础设施。

## 报告输出结构

```markdown
# <技术浪潮名称>历史周期映射分析

## 一、当前阶段定位
- 1.1 历史技术泡沫周期对比表
- 1.2 当前所处位置判断（6 阶段模型定位）
- 1.3 周期位置类比（附时间线对照图）

## 二、N大应用领域深度分析
- 每个领域：技术突破 + 实际进展 + 瓶颈 + 泡沫后逻辑 + 评分判断

## 三、泡沫破裂情景预测
- 3.1 参考历史触发因素对照
- 3.2 最可能触发因素
- 3.3 时间线预测
- 3.4 破裂后的基础设施遗产

## 四、核心判断（N 条）
- 每条为独立判断句 + 一句话论证

## 五、策略建议
- 按时间窗口分层建议

## 附录：关键数据来源
- 标注来源可靠性和时效性
```

## 数据来源优先级（该分析类型）

| 优先级 | 来源 | 说明 |
|--------|------|------|
| **S 级** | Wikipedia API（技术/经济条目） | 结构化事实数据，公开可验证 |
| **A 级** | 上市公司财报/公告 | 一手数据，但需解读 |
| **B 级** | IMF/央行报告、学术论文（NBER） | 权威但可能有滞后 |
| **C 级** | 投行研报（Goldman/Morgan Stanley/JPMorgan） | 有利益立场需交叉验证 |
| **D 级** | 媒体分析（FT/Bloomberg/WSJ） | 背景补充，不单独支撑关键结论 |
