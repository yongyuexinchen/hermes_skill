# 东方财富 API 字段映射表

> ⚠️ **关键警告**：东方财富有两个端点 — `stock/get`（单股）和 `ulist.np/get`（批量）。
> 这两个端点的**字段 ID 含义完全不同**！f164 在一个端点返回 PE(TTM)，在另一个端点返回无意义的巨量数字。
> 混用字段映射是最高频的错误。始终对照下方对应的表格，不要跨端点套用字段名。

## 端点一：个股实时行情（stock/get）——单股查询

**端点**：`https://push2.eastmoney.com/api/qt/stock/get`

**参数**：
- `secid`：`0.<深市6位代码>` 或 `1.<沪市6位代码>`（如 `0.002241` = 歌尔股份，`1.600276` = 恒瑞医药）
- `fields`：逗号分隔的字段编号列表

**关键字段**：

| 字段 | 含义 | 单位/说明 |
|------|------|----------|
| f43 | 最新价 | **分**（除以100得元） |
| f44 | 最高价 | 分 |
| f45 | 最低价 | 分 |
| f46 | 开盘价 | 分 |
| f47 | 成交量 | 手 |
| f48 | 成交额 | 分 |
| f50 | 量比 | 直接值 |
| f51 | 52周最高 | 分 |
| f52 | 52周最低 | 分 |
| f55 | 今日涨跌幅 | 直接值（0.05=5%） |
| f57 | 股票代码 | 字符串 |
| f58 | 股票名称 | 字符串 |
| f60 | 昨收 | 分 |
| f116 | 总市值 | 元（已换算） |
| f117 | 流通市值 | 元（已换算） |
| f162 | PE(静态) | **需÷100**（如1298→PE=12.98） |
| f164 | PE(TTM) | **需÷100**（如3140→PE=31.40）⭐ 估值分析首选 |
| f167 | 市净率(PB) | **需÷100**（如778→PB=7.78） |
| f168 | 换手率 | **需÷100**（如444→4.44%） |
| f170 | 量比 | 直接值 |
| f173 | ROE | **需÷100**（如1208→ROE=12.08%） |
| f183 | 营业总收入 | 元（最近一期） |
| f184 | 营收同比增长率 | 直接值（14.44→+14.44%） |
| f185 | 净利润同比增长率 | 直接值（7.28→+7.28%） |
| f186 | 净利润 | 元 |

**估值分析推荐字段组合**（stock/get）：
```
fields=f43,f57,f58,f164,f167,f184,f185,f51,f52,f116,f117,f173
```

**返回格式**：
```json
{
  "rc": 0,        // 0=成功
  "data": {
    "f43": 2369,  // 23.69元
    "f57": "002241",
    "f58": "歌尔股份",
    ...
  }
}
```

**使用示例**：
```bash
# 拉取歌尔股份估值全貌
curl -s --compressed \
  "https://push2.eastmoney.com/api/qt/stock/get?secid=0.002241&fields=f43,f57,f58,f164,f167,f184,f185,f51,f52,f116"

# 拉取金山办公（科创板，沪市）
curl -s --compressed \
  "https://push2.eastmoney.com/api/qt/stock/get?secid=1.688111&fields=f43,f57,f58,f164,f167,f184,f185,f51,f52,f116"
```

## 端点二：批量行情（ulist.np/get）——多股并发 ⚡

**端点**：`https://push2.eastmoney.com/api/qt/ulist.np/get`

适用场景：一次拉取 20+ 只股票时，用此端点替代逐只 stock/get（大幅减少请求数，规避速率限制）。

**参数**：
- `secids`：逗号分隔的股票 ID（格式同 stock/get，如 `1.688111,1.600588,0.002410`）
- `fltt`：固定为 `2`
- `fields`：⚠️ **字段 ID 与 stock/get 完全不同！** 见下表
- `ut`：固定为 `fa5fd1943c7b386f172d6893dbbdf45b`

**关键字段（ulist.np/get）**：

| 字段 | 含义 | 单位/说明 |
|------|------|----------|
| f2 | 最新价 | 直接值（元），无需÷100 |
| f3 | 涨跌幅 | 直接值（1.8→+1.80%） |
| f9 | PE(动态) | 直接值，无需÷100 |
| f12 | 股票代码 | 字符串 |
| f14 | 股票名称 | 字符串 |
| f20 | 总市值 | 元 |
| f21 | 流通市值 | 元 |
| f23 | PB | 直接值，无需÷100 |
| f37 | ROE | 直接值（15.7→ROE=15.7%） |
| f48 | 营收同比增长率 | 直接值（17.97→+17.97%） |
| f49 | 净利润同比增长率 | 直接值（86.59→+86.59%） |
| f115 | PE(TTM) | ⭐ **直接值**（31.4→PE=31.4），估值分析首选 |

**估值分析推荐字段组合**（ulist.np）：
```
fields=f2,f3,f12,f14,f20,f21,f23,f37,f48,f49,f115,f9
```

**使用示例**：
```bash
# 批量拉取 3 只科技股
curl -s --compressed \
  "https://push2.eastmoney.com/api/qt/ulist.np/get?fltt=2&secids=1.688111,1.600588,0.002410&fields=f2,f3,f12,f14,f20,f23,f37,f48,f49,f115&ut=fa5fd1943c7b386f172d6893dbbdf45b"
```

**返回格式**：
```json
{
  "rc": 0,
  "data": {
    "total": 3,
    "diff": [
      {"f2": 245.58, "f3": 1.8, "f12": "688111", "f14": "金山办公", "f115": 31.4, "f23": 7.78, ...},
      {"f2": 9.73, "f3": 2.1, "f12": "600588", "f14": "用友网络", "f115": -24.16, "f23": 4.82, ...}
    ]
  }
}
```

⚠️ **注意**：ulist.np 返回的 `data.diff` 中不保证顺序与 secids 一致。按 `f12`/`f14` 匹配所需标的。

## 端点对比速查

| 特性 | stock/get | ulist.np/get |
|------|-----------|-------------|
| 调用方式 | 单股，逐个请求 | 多股，逗号分隔 secids |
| 价格字段 | f43（分，÷100） | f2（元，直接值） |
| PE(TTM) | f164（分，÷100） | f115（直接值） |
| PB | f167（分，÷100） | f23（直接值） |
| 营收增速 | f184（直接值） | f48（直接值） |
| 利润增速 | f185（直接值） | f49（直接值） |
| 总市值 | f116（元） | f20（元） |
| 52周高低 | f51/f52（分，÷100） | ❌ 不可用（返回其他指标） |
| 港股支持 | `116.` 前缀（如 116.0268） | `116.` 前缀（可能空返回） |
| 速率限制 | 高频率触发封禁 | 批量一次，更耐受 |

## ⚠️ 注意事项

- **stock/get**：价格/PE/PB/52周高低 需 **÷100**；营收/利润增速（f184/f185）是直接值
- **ulist.np/get**：价格/PE/PB/增速/ROE 全部是**直接值**，无需 ÷100
- API 返回 gzip 压缩数据，curl 必须用 `--compressed` 参数
- **不要**用 browser_navigate 访问此 API（浏览器无法解码 gzip，会报 UTF-8 错误）
- 港股通过 `116.` 前缀访问（如 `116.0268` = 金蝶国际），但 ulist.np 对港股支持不稳定，建议港股用 stock/get 单独拉取
- **速率限制**：东方财富对连续请求有较严格的速率限制，表现为 ProxyError 或 RemoteDisconnected。对策：
  - 优先用 ulist.np 批量拉取 A 股（一次搞定）
  - 逐只 stock/get 时间隔 ≥1.5 秒
  - 实现 3 次重试 + 指数退避（2s/4s/8s）
  - 如果反复 ProxyError，等待 30 秒后重试
