# 产品全品类对比表 — 输出格式

> 适用场景：用户要求"产品对比表""全品类对比""各品牌PK""横评"等，需要输出一张覆盖多品牌多型号的结构化对比表。常搭配科技产业链调研（模式 B）或作为独立任务。

---

## 核心对比表字段（必备）

| 字段 | 说明 | 示例 |
|------|------|------|
| **品牌** | 品牌英文名/中文名 | XREAL / Rokid / 雷鸟(RayNeo) |
| **型号** | 产品具体型号 | Air 2 Ultra / Max / X2 |
| **发布时间** | 年月 | 2024.3 |
| **价格** | 首发价格（人民币/美元视地区） | ¥4,599 / $439 |
| **重量(g)** | 整机重量（含镜框） | 80g |
| **光学方案** | Birdbath / 衍射光波导 / 阵列光波导 / 自由曲面 / 碳化硅波导 | Birdbath + 电致变色 |
| **FOV** | 视场角（对角线度数） | 52° |
| **分辨率** | 单眼分辨率 + 显示器件型号 | 1920×1080/眼 (Sony 0.68" Micro OLED) |
| **亮度** | 入眼亮度（nit） | 500nit / 1500nit |
| **芯片平台** | SoC 或外接说明 | 高通 XR2 / 外接(DP) |
| **连接方式** | 有线(DP) / 无线蓝牙 / 一体式 | 有线 |
| **空间定位** | 3DoF / 6DoF / 无 | 6DoF (SLAM) |
| **场景** | 核心使用场景 | 观影投屏/空间计算/信息提示 |
| **亮点** | 差异化卖点 | 6DoF 空间定位、手部追踪 |
| **不足** | 主要短板 | 仍为有线、需外接计算单元 |

---

## 补充对比维度（按需追加）

- **透光率**：Birdbath ~30-50%，光波导 >85%
- **刷新率**：60Hz / 90Hz / 120Hz
- **续航**：一体式设备的电池容量和使用时间
- **接口**：USB-C DP / 专用磁吸 / 无线
- **兼容性**：支持哪些手机/PC/游戏机型号
- **配件生态**：计算盒子/颈带/手柄等

## 必备章节（非表格）

在对比表之外，必须覆盖：

1. **光学技术路线对比**：Birdbath vs 衍射波导 vs 阵列波导 vs 碳化硅波导 vs 自由曲面 — 每个路线的原理、FOV 范围、亮度效率、显示质量、体积、透光率、成本、代表产品
2. **技术演进时间线**：当前→过渡期→下一代的路线推演
3. **市场格局数据**：出货量估算（按品牌）、市场份额、融资热度
4. **趋势判断**：短期/中期/长期展望 + 关键变量（如 MicroLED 量产、苹果入局）
5. **数据可靠性说明**：标注哪些来自实时验证、哪些来自训练知识

---

## 网络搜索阻断时的回退策略（中国网络环境）

当百度/Google/Bing/DuckDuckGo 全部无法爬取时：

1. **快速试探（2-3 个源后即判定）**，不要在同一个被封锁引擎反复重试
2. **尝试 Python urllib 直接访问内容站**（如 GSM Arena、The Verge、Engadget 等），这些站可能未全面封锁
3. **全部失败后**：基于训练知识撰写，在报告末尾加「数据可靠性说明」表，逐项标注可靠度
4. **绝不编造**「实时查询结果」

## 反模式

- ❌ 把 VR/MR 设备（Quest 3、Vision Pro、Pico）和 AR 眼镜混在同一张对比表中（这是不同品类）
- ❌ 遗漏关键字段导致对比不完整（如遗漏 FOV、光学方案、重量）
- ❌ 在产品推出超过 1 年后仍不标注「已停产」
- ❌ 所有数据不标注来源/可靠度
