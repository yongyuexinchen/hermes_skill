# Capital Cycle Analysis — Hermes v3.0 资本周期模块设计

> **设计日期**：2026-07-29
> **定位**：v2.1 解决「谁赚钱」→ v3.0 解决「什么时候赚」
> **核心命题**：投资最终不是判断「未来有没有价值」，而是判断「未来价值什么时候超过当前价格」。

---

## 一、为什么需要资本周期

### v2.1 的盲区

v2.1 的六维评估回答的是**截面问题**：

> 这个方向在当下时间点，技术/商业/组织/行业/监管/壁垒各维度的状态如何？

但它不回答**时序问题**：

> 这个方向在时间轴上处于什么位置？市场已经 price in 了多少预期？

### 历史教训

工业 AI 在 v2.1 中六维评分可能很高（技术 5、壁垒 5、行业 5），但如果 5 年前已经被炒过一轮（2017 工业 4.0），当下市场预期已经透支了未来 3 年的增长——**方向对，买入时机错，依然亏钱。**

### 资本周期的核心问题

```
不是：这个行业 5 年后值不值钱？
而是：当前股价已经包含了多少 5 年后的预期？
```

## 二、五阶段模型

### 阶段定义

```
阶段 1: 萌芽（Nascent）
阶段 2: 爆发（Breakout）  
阶段 3: 过热（Overheating）
阶段 4: 出清（Washout）
阶段 5: 普及（Adoption）
```

### 各阶段特征

| 阶段 | 技术状态 | 市场叙事 | 资本行为 | 股价特征 | 典型信号 |
|------|---------|---------|---------|---------|---------|
| **1. 萌芽** | 实验室阶段，产品未定型 | 「这个东西很酷」——少数极客关注 | 天使/VC 早期布局 | 只有概念股，无实质业绩 | 顶会论文突破、原型 Demo 发布 |
| **2. 爆发** | 首个杀手级产品出现 | 「这个东西会改变世界」——主流媒体开始报道 | VC 大量涌入，估值快速攀升 | 龙头股暴涨，板块效应出现 | 标志性产品发布（如 ChatGPT 2022.11） |
| **3. 过热** | 技术被过度神化，预期远超现实 | 「所有行业都将被颠覆」——泡沫叙事 | 散户入场，IPO 井喷，跨界蹭概念 | PE 远超历史均值，概念股满天飞 | Shiller P/E > 40、非专业投资者大规模入场 |
| **4. 出清** | 技术回归真实能力边界 | 「这个东西是骗局」——过度悲观 | 资本撤离，破产潮，人才外流 | 暴跌 50-80%，龙头也扛不住 | 标志性公司破产/资金链断裂 |
| **5. 普及** | 技术在合理预期内渗透 | 「这个东西确实有用」——变得无聊但无处不在 | 产业资本主导，估值回归理性 | 业绩驱动而非概念驱动 | 渗透率突破 20% 进入主流 |

### 历史映射

| 技术浪潮 | 萌芽 | 爆发 | 过热 | 出清 | 普及 |
|---------|------|------|------|------|------|
| 铁路 | 1825 首条铁路 | 1830 利物浦-曼彻斯特 | 1845-1847 Railway Mania | 1847 崩盘 | 1850-1870 工业化黄金期 |
| 电力 | 1831 Faraday | 1882 Pearl Street | 1880s-1893 电力公司泡沫 | 1893 大恐慌 | 1910-1920s 流水线革命 |
| 互联网 | 1969 ARPANET | 1995 Netscape IPO | 1998-2000 dot-com | 2000-2002 NASDAQ -78% | 2004-2007 Web 2.0 |
| AI | 2017 Transformer | 2022.11 ChatGPT | 2023-2026（当前） | **2026-2027?** | **2029-2035?** |

### AI 各子方向当前阶段定位

| 方向 | 当前阶段 | 判断依据 |
|------|:---:|------|
| GPU/算力基建 | 过热 → 接近顶点 | Nvidia $5T、数据中心疯狂投入、循环投资 |
| LLM 模型层 | 过热 | OpenAI $150B+ 估值、年亏 $740亿、Sam Altman 承认泡沫 |
| AI 编程 | 爆发 → 早期过热 | Copilot 180万+付费用户，ARR 爆发增长 |
| AI 眼镜 | 爆发 | Meta Ray-Ban PMF 初步验证，竞品涌入 |
| AI 制药 | 萌芽 → 早期爆发 | AlphaFold 3 突破，但临床管线仍在早期 |
| AI 教育 | 萌芽 | 学习机出货量验证中，学校采购未启动 |
| AI 医疗影像 | 萌芽 → 爆发 | 技术成熟但商业闭环未形成 |
| 自动驾驶 | 过热（L4）→ 出清（叙事） | L5 叙事破裂，L2+ 实质渗透中 |

| 工业 AI | 萌芽 | 数字化基础薄弱，AI 渗透率极低 |

## 三、资本周期与六维评估的关系

### 两个维度，不同作用

```
六维评估 = 横向截面诊断
  「这个方向本身好不好？」

资本周期 = 纵向时序诊断
  「这个方向现在处于什么阶段？市场预期超前了多少？」
```

### 合并使用

| 六维得分 | 资本周期阶段 | 投资含义 |
|:---:|:---:|------|
| 高 (4+) | 萌芽/出清 | ✅ **最佳布局期**——方向好 + 市场未定价 |
| 高 (4+) | 过热 | ⚠️ **方向对但价格错**——等出清再买 |
| 高 (4+) | 普及 | 🟡 业绩验证期——看数据决定持有/卖出 |
| 低 (<3) | 任何阶段 | ❌ 方向本身有问题——不管什么阶段都回避 |
| 中 (3-4) | 出清 | 🟢 可能被市场过度悲观——逆向布局机会 |

### 决策矩阵

```
              六维评分
              低      中      高
          ┌───────┬───────┬───────┐
    萌芽   │  观望  │ 小仓研究 │ ✅重仓  │
    爆发   │  回避  │  观察   │ ✅建仓  │
资本 过热   │  回避  │  回避   │ ⚠️等待  │
周期 出清   │  回避  │ 🟢逆向  │ ✅重仓  │
    普及   │  回避  │  持有   │ 🟡持有  │
          └───────┴───────┴───────┘
```

### 关键原则

> **「高六维 + 萌芽/出清」= 最佳击球区。**
> 海康威视（工业 AI）正好在这个位置：六维高（技术+壁垒+行业都有），资本周期处于萌芽（市场完全不把它当 AI 股，PE 20）。

## 七、🔴 Cycle Mismatch Analysis（v3.0 强制）

### 核心洞察

最好的投资机会往往不是「产业周期 + 资本周期 双优」，而是**两者错位**。

```
产业周期（实际基本面）   资本周期（市场定价）   含义
═══════════════════════════════════════════════════════════
领先 (萌芽→爆发)        滞后 (未关注)           ✅ 最佳——市场还没发现
领先 (萌芽→爆发)        领先 (已经炒了)         ❌ 危险——预期已透支
稳健 (基本面 OK)         过度悲观 (出清/恐慌)     🟢 逆向——资本提前恶化
```

### 三种错位类型

#### 类型 A：产业领先 + 资本滞后（最佳击球区）

> 产业已在早期爆发，但资本市场完全没注意到。

| 要素 | 特征 |
|------|------|
| 产业时钟 | 萌芽 → 爆发（产品可用、渗透率开始爬升） |
| 资本时钟 | 萌芽（低关注、无分析师覆盖、PE 处于历史低位） |
| 错位方向 | 资本落后于产业 |
| 投资含义 | 在资本发现之前建仓——赚「认知差」的钱 |
| 当前案例 | 工业 AI（海康 PE 20）、视源股份（PE 28） |

#### 类型 B：产业滞后 + 资本领先（最危险）

> 产业还在极早期，资本市场已经透支了 5-10 年的预期。

| 要素 | 特征 |
|------|------|
| 产业时钟 | 萌芽（产品未定型、商业未验证） |
| 资本时钟 | 过热/爆发（高 PE、高关注、大量跨界涌入） |
| 错位方向 | 资本超前于产业 |
| 投资含义 | 坚决回避——等资本出清 + 产业追上，或永不投 |
| 当前案例 | 具身智能（Figure $390亿零收入）、科大讯飞（PE 111）、自动驾驶 L4 叙事 |

#### 类型 C：产业稳健 + 资本过度悲观（逆向机会）

> 产业基本面没有问题，但资本周期因外部冲击（泡沫破裂、行业恐慌）而过度悲观。

| 要素 | 特征 |
|------|------|
| 产业时钟 | 爆发/普及（需求真实存在） |
| 资本时钟 | 出清（股价暴跌、负面叙事主导） |
| 错位方向 | 资本先于产业恶化（但产业并未恶化） |
| 投资含义 | 逆向布局——赚「恐惧折价」的钱 |
| 当前案例 | 云计算/IDC（训练 GPU 空置恐慌 → 市场未定价推理需求爆发） |
| 历史类比 | 2002 年买 Amazon（互联网泡沫后 $7 → $3T+）、2003 年买光纤资产 |

### 错位矩阵

```
              资本周期
              萌芽      爆发      过热      出清      普及
          ┌───────┬───────┬───────┬───────┬───────┐
    萌芽   │ 中性    │ ❌B    │ ❌B    │ 无关    │ 无关   │
产业 爆发   │ ✅A     │ 中性    │ ❌B    │ 🟢C    │ 无关   │
周期 过热   │ 无关    │ ✅A     │ 中性    │ 🟢C    │ 无关   │
    出清   │ 无关    │ 无关    │ ❌B    │ 中性    │ 🟢C   │
    普及   │ 无关    │ 无关    │ 无关    │ 🟢C    │ 中性   │
          └───────┴───────┴───────┴───────┴───────┘

✅A = 产业领先 + 资本滞后 → 最佳击球区
❌B = 产业滞后 + 资本领先 → 最危险陷阱
🟢C = 产业稳健 + 资本过度悲观 → 逆向机会
```
