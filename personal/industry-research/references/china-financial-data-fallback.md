# 中国网络下金融数据获取：终极回退指南

> 当 API、搜索引擎、行情页全部不可用时的最后通道。
> 更新时间：2026-07-30，基于半导体数据回测验证。

## 问题场景

在中国大陆网络下获取美股/港股/全球指数实时数据时，所有常规渠道可能同时失效：

| 渠道 | 典型失败模式 |
|------|------------|
| 东方财富 push2 API | `exit_code 56`（连接被拒）、代理断连 |
| 搜狗 web 搜索 | CAPTCHA 验证码页面（`seccodeForm`） |
| 百度 web 搜索 | `wappass.baidu.com` CAPTCHA 拦截 |
| Yahoo Finance | 中国大陆全面屏蔽（2021.11起） |
| Google Finance | GFW 阻断 |
| 东方财富个股页 | JS 渲染，API 调用在境内网络失败 → 数据字段全 `-` |
| Alpha Vantage / Twelve Data | demo key 被限，正式 key 需注册 |

## ✅ 可用回退：东方财富站内新闻搜索

**URL 模式**：
```
https://so.eastmoney.com/news/s?keyword=<URL编码的关键词>
```

### 已验证的搜索模板

**美股指数**：
```
https://so.eastmoney.com/news/s?keyword=费城半导体指数+SOX+2026年7月
```

**个股搜索**：
```
https://so.eastmoney.com/news/s?keyword=英伟达+2026年7月+股价
https://so.eastmoney.com/news/s?keyword=台积电+TSM+2026年6月
```

**汇率**：
```
https://so.eastmoney.com/news/s?keyword=新台币+汇率+2026年7月
```

### 搜索结果特征

- 新闻片段包含**具体数字**：涨跌幅百分比、个股价格、指数点位
- 快讯类结果（东方财富全球财经快讯）数据密度最高
- 每个结果有**精确时间戳**（精确到秒）
- 可提取的信息：盘中涨跌幅、开盘涨跌幅、成分股明细变动

### 数据提取方法

1. **browser_navigate** 访问搜索 URL
2. **browser_snapshot** 获取页面文本（不需要 JS 渲染，关键数据在文本中）
3. 手动解析新闻标题和摘要中的数字
4. 交叉验证多个搜索结果的一致性

### 典型产出示例

从 `费城半导体指数+SOX+2026年7月` 搜索中获取：

```
2026-07-28：SOX 跌超5%，美光-8%+，SK海力士-6%+，英特尔/ASML -5%+
2026-07-29：SOX 跌超4%→跌近4%→跌幅3.10%
2026-07-29 成分股：Arm -5.25%, AMD -4.15%, 泛林 -3.82%, 美光 -3.63%, 
              英伟达 -2.89%, 台积电 -2.83%, 英特尔 -2.50%, ASML -1.99%
```

### 局限性

- **无法获取精确指数点位**（如 SOX 从 xxxx 跌到 yyyy），只能获取涨跌幅百分比
- **依赖新闻覆盖**：非热门标的可能没有快讯
- **数据粒度为"盘中"**：通常是当日盘中数据，不是收盘数据
- **历史数据受限**：搜索侧重近期新闻，历史回溯有限
- **端点依赖**：需要 `so.eastmoney.com` 域名可达（已验证中国网络下可达）

## 使用优先级

```
1. 腾讯行情 API (qt.gtimg.cn)         ← 最快最稳定
2. 东方财富 push2 K线 API             ← 历史日线数据
3. 🔴 东方财富新闻搜索 (so.eastmoney.com) ← 当 1-2 都失败时的实时回退
4. browser_navigate 到东方财富个股页    ← JS 渲染可能失败
5. 训练知识                              ← 最后手段，必须标注 [训练知识]
```
